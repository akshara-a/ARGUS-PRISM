# ARGUS PRISM Local Execution & Development Launchers

This directory contains one-click local launch scripts for Windows development:

| Launcher | Service / Task | Endpoint / Description |
| :--- | :--- | :--- |
| `run_all.bat` | Full Stack Orchestration | Launches both FastAPI backend and Next.js Studio simultaneously. |
| `run_api.bat` | FastAPI REST Backend | Runs the REST API server at `http://localhost:8000`. |
| `run_frontend.bat` | Next.js 16 Studio | Runs the React 19 Studio at `http://localhost:3000`. |
| `run_dashboard.bat` | Streamlit Evidence Inspector | Runs the interactive graph dashboard at `http://localhost:8501`. |
| `run_demo.bat` | 6-Act Showcase Demo | Executes the complete deterministic judge showreel in ~1.4s. |
| `run_benchmark.bat` | 7-Point Benchmark Suite | Runs automated evaluation tests (Hallucination trap, contradiction catch, etc.). |
| `run_mcp.bat` | MCP 2.x Server | Runs Model Context Protocol server over stdio for AI agent connection. |
| `run_compare.bat` | CLI Tech Stack Comparator | Compares two technologies (e.g. FastAPI vs Django) across 4 dimensions. |
| `run_dossier.bat` | Enterprise HTML Dossier | Generates a standalone HTML evidence dossier. |
| `run_telemetry.bat` | Cost-Guard Telemetry | Inspects cache hit rates, query economics, and USD cost savings. |
